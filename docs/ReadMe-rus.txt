Мод для AI Roguelite: "Скрыть ввод игроков"
===========================================

Что делает
----------
Прячет из игрового лога то, что написали игроки. ИИ игры при этом получает
написанное целиком, без изменений - меняется только то, что видно на экране.
Нужно для совместной игры, чтобы заранее не видеть ход напарника.

Было:   Сэр Алдрик: тихо подкрадываюсь к сундуку и вскрываю замок отмычкой
Стало:  Сэр Алдрик совершает действие


Установка
---------
1. Распаковать всё содержимое этого архива в папку игры - туда, где лежит
   файл "AI Roguelite.exe". Обычно это:

   ...\Steam\steamapps\common\AI Roguelike

   Найти папку проще всего через Steam: правой кнопкой по игре ->
   "Управление" -> "Посмотреть локальные файлы".

2. Запустить игру как обычно. Больше ничего делать не нужно.

Всё. Подписка и мастерская для мода не нужны.


Как убедиться, что мод работает
-------------------------------
В папке игры появится файл BepInEx\LogOutput.log, в нём должно быть:

   [Info   :   BepInEx] Loading [Скрыть ввод игроков 1.0.0]
   [Info   :Скрыть ввод игроков] Патч на MakePlayerInputInfoTxt поставлен.

А в самой игре после любого действия в логе вместо текста будет
"Имя совершает действие"


ВАЖНО про совместную игру
-------------------------
Мод нужен обоим игрокам. Текст в логе каждый рисует у себя на компьютере,
поэтому если мод стоит только у одного - второй всё равно увидит всё.


Настройки
---------
После первого запуска игры появится файл:

   BepInEx\config\shantargon.airoguelite.hideplayerinput.cfg

Его можно открыть блокнотом, все подписи на русском. Там можно:
  - скрывать всё / только чужое / ничего;
  - поменять текст-заглушку: "{имя} совершает действие", "{имя}: ...",
    "{имя} что-то задумал" или просто "..." без имени;
  - сменить клавишу показа (по умолчанию F9 - показать/снова скрыть лог).


Как удалить
-----------
Удалить из папки игры: winhttp.dll, doorstop_config.ini, .doorstop_version
и папку BepInEx. Игра вернётся в исходное состояние.
